# qr_code_generator_python
A simple Python script that creates qr code from different UPI ids for different payment apps.

##Features
-Generate aQR code from any UPI ID.
-Save QR code as png format .
-Generate QR code for Gpay, paytm, phonepay.

## Requirements
-Python 3.14
-'qr code' library
-'Pillow' library

##Installation
-pip install qrcode[pil]
